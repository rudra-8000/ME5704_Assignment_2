# ME5704 Group Project 2 — Plate heat conduction

Steady-state temperature (part a), heat flux (part b) and absorbed heat (part c) for a 4x4 plate with a
350 K source line at x = 1.5, 2 <= y <= 3 and 200 K edges.

```
code/shared/plateProblem.m      problem data shared by all parts
code/part_a/                    part (a): run_part_a.m reproduces every number, table and figure
  core/ solvers/ transient/ montecarlo/ experiments/ tests/ results/
code/part_b/  code/part_c/      teammates' code
report/main.tex                 LaTeX report (Overleaf: upload the whole repo, main file = report/main.tex)
report/figures, report/tables   generated by code/part_a (do not edit by hand)
```

## Run part (a)

MATLAB (base install, no toolboxes), from any folder:

```matlab
run('code/part_a/run_part_a.m')    % ~30 s; writes results/, report/figures/, report/tables/
```

`code/part_a/results/part_a_temperature.csv` is the interface for parts (b) and (c):
`T_cubic_h1` = answer on the given h = 1 data, `T_sw_h1` = alternative treatment, `T_reference` = mesh-converged estimate.
